# Retrofit Subcontractor Bidding Marketplace

## Overview
This project is being developed as a Proof of Concept for my MSc Placement Project at the Technological University of the Shannon (TUS).

The application enables Project Managers to post retrofit jobs and allows Contractors to browse available jobs and submit bids.

## Technologies

- Java 21
- Spring Boot 3.5
- Spring Security
- Spring Data JPA
- PostgreSQL
- React
- Docker
- JWT Authentication
